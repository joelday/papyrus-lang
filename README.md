# 📜 Papyrus Language Tools

[![Discord](https://img.shields.io/discord/558746231665328139.svg?color=%23738ADB)](https://discord.gg/E4dWujQ)

A compiler, language server and Visual Studio Code extension for Papyrus, the scripting language of Skyrim, Fallout 4 and Starfield.
